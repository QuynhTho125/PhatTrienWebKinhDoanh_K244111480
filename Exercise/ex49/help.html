Online Classifieds Help Page

1. Search Sections

Select one classified section that you want to search.

  • Employment: search for job advertisements.
  • For Sale: search for products or items for sale.
  • Housing: search for houses, rooms, or apartments.
  • Personal: search personal classified ads.
  • Miscellaneous: search other kinds of advertisements.
  • All of the above: search in every section.

2. Publications

Select one or more publications. You can check many boxes at the same time.

3. Date Range

Use the date fields to choose the starting date and ending date for your search.

4. Keywords

Enter important words that describe the classified ad you want to find.

Example: car, apartment, designer job, laptop, furniture.

5. Buttons

  • Search: displays the search simulation message.
  • Help: opens this help page.
  • Cancel: clears all data selected or entered on the form.
